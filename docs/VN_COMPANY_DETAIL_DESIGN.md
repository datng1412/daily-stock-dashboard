# VN Company Detail Design

## Goal

Turn company detail into a data-quality report.

## Layout

### 1. Header / Hero

Fields:
- ticker
- exchange
- latest price
- price date
- canonical source
- data status

Badges:
- Daily OK
- Profile partial
- Live unavailable
- News disabled
- No recommendation

### 2. Data Quality Summary

Cards:
- Source mismatch
- Final close status
- Adjusted price status
- Intraday status
- Realtime status
- Trade tape status
- Metadata status

### 3. Daily Core Data

- Price Summary
- Trading Stats
- Foreign Flow
- Technical Snapshot

### 4. Live Data Availability

- Intraday
- Realtime
- Trade tape

### 5. Future Modules

- News
- Financials
- Events

### 6. Diagnostics

Collapsible only.
