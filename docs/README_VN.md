# Vietnam dashboard setup

Start with the [Vietnam runbook](RUNBOOK_VN.md#live-ssi-mode) for configuration, launch, and verification. Use the [Windows runbook](RUNBOOK_LOCAL_WINDOWS.md) for Windows-specific steps and the [Docker and Render runbook](RUNBOOK_DOCKER_RENDER.md) for hosted operation.

The workspace is available at `/vietnam`. A new browser starts with an empty watchlist prompt. Pick a preset or add symbols to save a browser-local list. The general `STOCK_LIST` configuration does not prepopulate that page.

See [Project State](PROJECT_STATE.md) for capability and acceptance status, [UI states](UI_STATES.md) for screen behavior, and the [VN data contract](VN_DATA_CONTRACT.md) for field ownership and limitations.
